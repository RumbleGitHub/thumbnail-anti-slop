# Real-image validation kit

Generated by `tests/quality-lab/real-image-kit.mjs` on 2026-11-07. Models: OPENAI_GPT_IMAGE_2_5_SUNBURST, MIDJOURNEY_V8_2.
BEFORE = engine at `baseline-ed55fbf`; AFTER = this working tree.

**This file contains prompts, not results.** Visual quality is only proven by generating both prompts with the same model and settings and scoring the images below.

## Procedure (about 30-45 min per model)

1. Use one model and keep its settings fixed (same quality, aspect ratio 16:9, no style presets). Use the same reference photos for BEFORE and AFTER.
2. For each case, generate **2 images from BEFORE** and **2 from AFTER** (a new chat/session per prompt, so earlier images do not leak in).
3. Attach references exactly as listed. For Midjourney V8.2, follow the AFTER notes (Edit Model, "Attach to prompt"); for BEFORE, attach the same images the same way, so only the text differs.
4. Without knowing which is which (ask someone to shuffle, or rename the files A/B), score each image 0/1/2 per defect: 0 = absent, 1 = minor, 2 = clearly wrong. Mark n/a when the defect cannot occur.
5. Sum per prompt version. A version wins a case only if its total is lower in both images. Note the worst defect you see.

| Defect | What counts |
|---|---|
| Produto incorreto | produto errado, genérico, fundido ou com botões/portas inventados |
| Capa falsa | arte ou título de capa inventado / ilegível (só casos com capas) |
| Falha de identidade | rosto não reconhecível como o da referência |
| Luz artificial | neon, rim light sem fonte, brilho plástico, HDR |
| Interação física | mãos/dedos/pegada impossíveis, objeto atravessando a mão |
| Composição fraca | assunto pequeno ou ilegível em 120px, poluição visual |
| Texto incorreto | texto diferente do pedido, letras derretidas, texto extra |
